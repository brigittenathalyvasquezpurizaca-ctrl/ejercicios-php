# Ejercicios de lógica en PHP

## Descripción

Este repositorio contiene 10 ejercicios de lógica de programación desarrollados en PHP como parte de la práctica de fundamentos de programación.

## Ejercicios realizados

1. Suma de números
2. Cálculo de promedio
3. Número mayor
4. Tabla de multiplicar
5. Factorial
6. Serie Fibonacci
7. Contador de vocales
8. Palíndromos
9. Inversión de cadenas
10. Búsqueda simple

## Organización

Cada ejercicio se encuentra organizado en una carpeta independiente:

* `01-suma`
* `02-promedio`
* `03-numero-mayor`
* `04-multiplicacion`
* `05-factorial`
* `06-fibonacci`
* `07-contador-vocales`
* `08-palindromos`
* `09-inversion`
* `10-busqueda`
